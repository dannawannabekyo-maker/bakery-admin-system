# Local assets drop-folder

Place your prepared assets here. Suggested structure:

```
assets/
  products/        # product photos — <slug>.jpg / .png / .webp
  categories/      # optional category banners
  branding/        # logo, favicon, hero images
  copy/            # text content: about.md, faq.md, product-descriptions.csv, etc.
```

In **STEP 2 / later steps** these are uploaded to Supabase Storage buckets:

- `product-images` (public) — product & category images
- `payment-receipts` (private) — generated by the checkout flow

Nothing in this folder is bundled into the app; it is source material only.
